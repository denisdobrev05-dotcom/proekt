# 🇧🇬 Топ 5 забележителности в България

Интерактивен едностраничен сайт, който представя петте най-впечатляващи
български забележителности. Изграден изцяло с **HTML, CSS и ванилов JavaScript** —
без външни зависимости и без процес на компилиране.

## ✨ Какво включва

- **Hero секция** с анимиран фон и статистики
- **Интерактивни карти** с подредба по рейтинг (#1 – #5)
- **Филтри** по категория: Култура, Природа, История
- **Модални прозорци** с подробна информация и любопитни факти
- **Интерактивна карта** на България с пулсиращи точки
- **Светла / тъмна тема** със запазване в браузъра
- **Плавни анимации** при скролване и прогрес лента
- **Напълно адаптивен** дизайн за мобилни и десктоп

## 🏛️ Забележителностите

1. Рилски манастир
2. Седемте рилски езера
3. Старият Несебър
4. Античен театър, Пловдив
5. Белоградчишки скали

## 🚀 Стартиране

Отвори `index.html` директно в браузъра, или пусни локален сървър:

```bash
python3 -m http.server 8000
# след това отвори http://localhost:8000
```

## 📁 Структура

```
index.html   – структура на страницата
styles.css   – оформление, теми и анимации
script.js    – данни и интерактивна логика
```
